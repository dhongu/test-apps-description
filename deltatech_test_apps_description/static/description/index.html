Overview

Internal test module of Terrabit, with no features. Its page on Odoo Apps checks how the store renders a module description: external images served by terrabit.ro (the animated count of the modules, SVG and GIF), inline SVG with animation, CSS animation, and the elements the store strips (iframe, script). Do not install it.
